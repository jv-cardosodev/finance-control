# 💰 FinanceControl

Sistema de controle financeiro pessoal desenvolvido com **HTML, CSS e JavaScript**.

O FinanceControl foi criado para facilitar o controle de finanças, permitindo registrar entradas, saídas e acompanhar a organização financeira através de um dashboard.

## 🚀 Funcionalidades

- ✅ Cadastro de usuários
- ✅ Login com email e senha
- ✅ Controle de sessão
- ✅ Dashboard financeiro
- ✅ Cadastro de movimentações
- ✅ Registro de entradas e saídas
- ✅ Categorias de gastos
- ✅ Histórico financeiro
- ✅ Gráficos de movimentação
- ✅ Sistema de logout

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Chart.js
